## Blinding and workload

Pool and shuffle unique root results for each intent/scope; hide model, rank, score, retrieval channel and model-membership count. At most24×2×8×10=3,840 retrieved memberships exist before overlap and compatible pair reuse, plus independently proposed references. Reference candidates are gathered before model outputs are viewed, enter the common judgment ideal only, and are hidden as references. Their useful adjudicated ranks/coverage are nonexhaustive, not corpus recall. Reuse a judgment across scopes only when the same intent and applicability hold; retain both observation memberships. Enumerate actual pool size before assigning work rather than committing to an unrealistic review duration.

All pooled roots receive one primary source review. Select a deterministic10% second-review overlap before seeing grades, stratified across categories and scopes: approximately384 at the maximal retrieved pool, with additional reference judgments increasing the actual overlap count, plus dispute adjudication. Deduplicate across all eight configurations before assigning work; configuration membership remains hidden. Reviewers receive full source paths, frozen intent/rubric and anonymous IDs; bind source paths/hashes once in the coordinator manifest and require reviewer JSON pointers and short literal evidence. Cross-kind useful owner answers count when actually supported. Prior source familiarity is disclosed, not confused with model-label blindness.

Resolve every overlap grade disagreement, including0/1 and2/3, or disagreement about opposite function through a third source adjudication, preserving both initial grades. Report agreement and disagreement rates on the overlap; that sample does not establish correctness of every singly reviewed label. If disputes exceed the bounded initial workload, pause to disclose the extra review rather than silently omitting them. Validate complete ID coverage, all referenced pointers/hashes and paired-scope consistency before unblinding.

Prepare a user-review packet containing every unresolved grade/flag dispute, with a short first page of up to12 concrete examples and a complete linked appendix. Include one concept per category selected deterministically before outputs, so the qualitative review is not only the largest measured gains. Record any later user adjudication as a separate version; do not overwrite the blinded originals or change the frozen query criteria.

## Uncertainty and decision

Use one clear primary comparison family: all seven alternative configurations versus BGE-small/current. This includes three model replacements at current representation, baseline-small with parent context, and three combined model/context replacements. Report95% descriptive intervals and conservative99.285714% per-contrast intervals (Bonferroni seven-comparison familywise view). Use50,000 seeded stratified concept-cluster bootstrap replicates, drawing four concepts per category and preserving all eight configurations and both scopes jointly. The same shared source labels and bootstrap draws must support every contrast. These small-sample intervals are descriptive approximations, not guaranteed population coverage.

Also predeclare explanatory factorial contrasts: each of the four within-model parent-context deltas; the equal-weight average of those four deltas; and each candidate model context delta minus the small-model context delta (three difference-in-differences). Report the three current-representation model changes explicitly, and optionally average each model-versus-small difference over both representations as a descriptive marginal model effect. The former tells us whether a model replacement helps without reshaping; the latter/context interactions reveal whether gains depend on reshaping. These explanatory analyses use95% intervals and are not additional independent confirmation claims. An average effect describes these four fixed model packages and two recipes, not all possible models or parent-context strategies.

Publish the full eight-configuration table, including losses. Do not declare the best observed cell a confidently superior winner merely because its unadjusted interval looks favorable. Selecting a configuration from this holdout carries winner-selection uncertainty; do not tune excerpt lengths, model prompts, or query subsets afterward and retain a fresh-evaluation claim. Label uncertainty, category tradeoffs and cost remain material even with adjusted intervals.

Opposite-function errors and category losses are important tradeoffs, not a zero-error veto. Conversely, higher average nDCG alone does not justify adoption. Present overall usefulness, ranking improvement, uncertainty, diversity of gains, specific regressions, semantic name controls, startup/query/build latency and resource costs for an explicit user decision. No new numeric adoption threshold is invented here. Inconclusive evidence favors retaining the baseline; changing prompts or policies after this evaluation consumes these concepts as development data and requires a new independently authored fresh set for another generalization claim.
