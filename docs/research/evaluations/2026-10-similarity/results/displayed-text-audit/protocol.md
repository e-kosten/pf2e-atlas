# Exploratory displayed-excerpt support audit

This is a separately declared follow-up to the frozen similarity experiment. The six cells and first-two-result rule were declared before captures (predeclaration SHA256 eac4ad2e8b60c6f0772536d22041ac8e5d8bbb9fcf8eaf523cf33a8c17b58430). No returned candidate was substituted. Rubric and packet packaging were specified after capture, before any fresh review; the preparer saw candidate identities and source material but assigned no semantic grades. This does not amend the frozen24-scenario protocol or its existing opinions, metrics, holdout, or defaults.

Twelve candidate explanations are retained. New-method packets contain exactly the Seed text and Match snippet/labels/navigation rendered by SimilarityExplanation. Baseline packets contain exactly SearchMatchContext matching_sections text/labels/navigation. Eighteen passage pairs and three baseline entries are present; one baseline entry is identity-only without passage text. No missing excerpt is manufactured. Numerical contribution tables, scores, weights, model/method identifiers, result ranks and method-specific framing notices are withheld. Naturally different numbers/shapes of passages remain visible, so structural inference is a residual blinding limit.

All displayed strings are copied from actual archived productCLI JSON at frozen generation6. The preparer checks citations separately: exactnavigation and passage guard acceptance by canonical recordget, matching artifact generation, original source bytehashes, exact selected-seed-part applicability, and diagnostic text-prefix containment in the checked canonical field. The existing read-only viewer converts HTML only for containment diagnostics, never for source segmentation or generating displayed excerpts. A valid citation is not proof of a meaningful semantic connection.

A fresh isolated reviewer receives only the blind packet index, its12 public packets, listed canonical source pointers and the separate judge instructions. It assesses semantic connection support, scope fit and ownership at both displayed-item and candidate-explanation level. It does not judge numeric cosine, ranking quality, score contribution, method superiority or citation correctness. All reference context is explicitly marked as sourcecontext, not additional displayed text.

Report item/candidate counts descriptively, preserving unknowns and identity-only text limitations. This small purposive first-two-result sample spans record/trait scopes and multiple methods/profiles, but is not a representative corpus-wide estimate or a confirmatory quality/default test. Original source bodies, captures and crosswalk remain ignored; eventual tracked conclusions retain paraphrases, bounded pointers and bytehashes.
