# Product Color System

Status: done
Last reviewed: 2026-10-25

PR108 delivered one coherent Atlas identity: Parchment and Oxblood in light
appearance and warmer Oxblood and Brass in dark appearance. Light, Dark and
System remain the only appearance choices. Theme definitions own the authored
palette, Ant projections and product-specific CSS roles.

Rarity uses visible neutral common, lighter copper uncommon, oxblood rare and
purple unique badges. HP uses green healthy, amber wounded, red critical, and
sage/light or parchment/dark temporary HP. Include and exclude filters retain
distinct semantic treatments. Selected, navigation, table and workbench surfaces
consume complete theme roles rather than feature-local color overrides.

The finishing brand pass adds the Lora `PF2e Atlas` wordmark, the theme-driven
ring-compass/d20 mark, simplified light and dark favicons and a dedicated
high-contrast action-glyph role. The durable role mappings and editing rules live
in `web/atlas-ui/docs/theme-design.md` and the frontend guidelines.
