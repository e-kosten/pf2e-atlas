# Effect Reference Presentation

Status: planned
Priority: soon
Owner: unassigned
Last reviewed: 2026-10-18

## Outcome

Define a consistent, code-documented policy distinguishing explanatory references
from references to applied effects. Preserve source data and relationships while
avoiding redundant reading destinations. Research and implementation belong in
a separate workstream and commit from shared presentation polish.

## Research

Inspect representative spell, item and ability references, including exceptions.
Schadenfreude and Heroism largely repeat their effects' descriptions; Bless
links an aura to an applied effect; Runic Weapon adds weapon selection; Mirror
Image uses a counter without rule elements. Enlarge Companion's effect expands
mechanics that its spell incorporates through a reference to Enlarge.

Determine which available source relationships reliably describe the reference's
role. Neither an effect type, name prefix, presence of rules nor similar prose
alone proves a reading link redundant. Account for useful standalone effect
records and links that explain additional mechanics.

## Acceptance

- Review the proposed universal policy with the user before suppression changes.
- Document the decision and exceptions beside the owning implementation.
- Test both redundant application references and useful reading references.
- Preserve underlying effect data for future encounter application, duration,
  counters and automation; this task does not implement that automation.
- Retain existing links until a supported policy is agreed.
