# Apply supported effects to encounter participants

Status: proposed

Follow-up to CF-07, separate from the condition-system replacement. Let a GM apply
supported spell/ability effects through the same condition flow, with source-derived
parameters, duration, action restrictions and targets prefilled for review.
For example, a supported Quickened-granting effect can supply its extra-action uses.

Reuse the shared condition commands, provenance, applicability checks, event planning
and retry protection. Casting or recording expenditure does not establish success:
require the relevant outcome and target confirmation before applying consequences.
Support explicit recipes with real source evidence, not spell-name inference or
arbitrary Foundry execution. Preserve manual entry and custom guidance without
pretending free-text restrictions are executable predicates.

CF-07 designs the receiving contract and restriction editing; recipe extraction,
spell-to-effect navigation and application automation belong to this follow-up.
Validate source references against the chosen upgraded PF2e pin when work begins.
