# General-definition test fixture notices

These test-only authored fields and localized rules come from the selected files
in `foundryvtt/pf2e` at commit `28d9d156f252d084371d994dc359509b49eadf18`.
The fixture records source identity beside its exact fields; it is not an
independent product content source.

- The eight general glossary templates are published as Pathfinder Monster Core
  content under ORC. Wind-Up is Pathfinder Monster Core 2 content under ORC.
  The pristine upstream [ORC notice and credits](upstream-notices.json) are retained here.
  The [complete ORC license](../../../../atlas-ingest/reference-data/orc-license.pdf)
  is retained in the repository's approved reference assets.
- Golem Antimagic is Pathfinder Bestiary Open Game Content under OGL 1.0a.
  The pristine upstream [OGL license and complete attribution chain](upstream-notices.json)
  is retained here, including the original Bestiary attribution below.
The pristine upstream texts are stored as JSON strings with their pinned paths,
URLs and SHA-256 hashes. Decoding these strings recovers the exact upstream bytes,
including existing trailing whitespace, without changing repository formatting
rules.

- Authored editing headers and game rules have these game-content permissions;
  the source repository's Apache license for code is not their permission route.
